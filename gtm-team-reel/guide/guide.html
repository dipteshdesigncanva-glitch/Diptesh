STEP 1 / 5 · STRATEGIST

Create the Claude Project

Pehle Claude ko tumhara business samjhao. Everything else builds on this.

Set it up

  1. Open claude.ai → Projects → + New project. Name it GTM Command Center.
  2. Paste the project instructions below into the project's instructions field.
  3. Start a chat inside the project, send the starter prompt, and answer one question at a time.
  4. Copy the final Business Brief into a document and add it to the project's knowledge, so every future chat starts with it.
PROJECT INSTRUCTIONSYou are the in-house marketing team for [BRAND NAME]. You work as five specialists: Strategist, Spy, Writer, Filmmaker and Publisher. Always follow the Business Brief and Brand Voice saved in this project. Write in [LANGUAGE / TONE, e.g. simple Hinglish]. Never invent facts, prices or features. Always show me a draft and wait for my approval before you publish, schedule or generate paid media.
STARTER PROMPTInterview me about my business, my customers and my competitors. Ask one question at a time. When you have enough, write a one-page Business Brief covering: what we sell, who buys it and why, our top 3 competitors, our positioning, and 3 growth goals for the next 90 days.
Tip: if Claude's memory is turned on for your account, it will also remember details across chats. Saving the Brief to project knowledge works either way.

STEP 2 / 5 · SPY

Connect Firecrawl MCP

Competitors analyse karo aur apni brand voice banao. Firecrawl lets Claude read any website.

Connect it

  1. Sign up at firecrawl.dev and copy your API key from the dashboard.
  2. In Claude, open Settings → Connectors → Add custom connector.
  3. Paste Firecrawl's hosted MCP URL from their docs (docs.firecrawl.dev → MCP Server). For claude.ai it currently looks like the line below, with your key in place of YOUR_API_KEY.
  4. Open a chat in your project and switch Firecrawl on from the tools menu.
https://mcp.firecrawl.dev/YOUR_API_KEY/v2/mcp
Keep that URL private: it contains your API key. Using Claude Desktop instead? Firecrawl's docs also cover a header-based setup and a local option (npx -y firecrawl-mcp with FIRECRAWL_API_KEY set).
PROMPT · COMPETITOR ANALYSISUse Firecrawl to read the homepage, pricing page and about page of [COMPETITOR A URL], [COMPETITOR B URL] and [COMPETITOR C URL]. For each one, tell me: what they sell, their price range, their main promise, who they target, any offers running now, and one gap we could own. End with a comparison table.
PROMPT · BRAND VOICEUsing our Business Brief and this competitor analysis, write our Brand Voice guide: 3 voice traits with do / don't examples, words we use, words we never use, and 5 sample lines. Keep it bold, simple and Hinglish-friendly.
Then: save the Brand Voice guide to project knowledge, next to the Business Brief.

STEP 3 / 5 · WRITER

Generate SEO content

The Writer is Claude itself, now armed with your Brief, your Brand Voice and Firecrawl research.

PROMPT · SEO BLOGAct as the Writer. Use Firecrawl to search for "[TARGET KEYWORD]" and read the top-ranking articles. Then write a 1,200-word blog in our Brand Voice that covers everything they cover, plus one angle they miss. Include: an SEO title under 60 characters, a meta description under 155 characters, H2 / H3 structure, an FAQ section, and 3 internal link ideas.
Example topic: "10 Meta Ads mistakes D2C brands make". Pick keywords your customers actually search, and fact-check any numbers before publishing.
PROMPT · A WEEK OF LINKEDIN POSTSTurn this blog into 3 LinkedIn posts for this week: one story, one tips list, one contrarian take. Each under 1,300 characters, with a strong hook in the first line, a maximum of 3 hashtags, and a question at the end to drive comments.

Make it better every week

  • Paste your best-performing post and ask: "What made this work? Write 3 more like it."
  • Keep a "Swipe file" document in the project with hooks and posts you love.
  • Edit the drafts in your own words. AI drafts, you add the final 10%.

STEP 4 / 5 · FILMMAKER

Product videos with Higgsfield + Remotion

A · UGC-style ads with Higgsfield MCP

  1. Create a Higgsfield account. Every video uses your Higgsfield credits.
  2. In Claude: Settings → Connectors → Add custom connector, paste the Higgsfield MCP URL from higgsfield.ai/mcp (the official server runs at mcp.higgsfield.ai), then sign in.
PROMPT · UGC ADWrite a 15-second UGC-style ad script for [PRODUCT] for Instagram Reels: a hook in the first 2 seconds, the problem, the product moment, and a clear CTA. Show me the script first. After I approve it, use Higgsfield to generate a vertical 9:16 video.

B · Product demos with Remotion (in Claude Code)

Remotion turns code into video, and its official skills teach Claude Code how to use it. Run these in your terminal:

npx create-video@latest cd my-video npx skills add remotion-dev/skills claude
PROMPT · PRODUCT DEMO (IN CLAUDE CODE)Using Remotion, make a 20-second 16:9 product demo for [PRODUCT] in 4 scenes: the problem, the product UI, 3 key features, and a CTA. Use our brand colours [HEX CODES]. Only use these features, don't invent any: [FEATURE LIST].
Preview with npm run dev (Remotion Studio), then ask Claude Code to render the final MP4. Expect a round or two of fixes. Treat your first prompt as a brief, not a final render.

STEP 5 / 5 · PUBLISHER

Publish + Command Center

Connect Typefully

  1. Create a Typefully account and connect your LinkedIn (X, Threads, Bluesky and Mastodon work too).
  2. Add Typefully's official MCP server in Claude → Settings → Connectors. The URL and sign-in steps are in Typefully's Help Center, under "Typefully MCP server".
PROMPT · SCHEDULESchedule the 3 LinkedIn posts we approved in Typefully for Monday, Wednesday and Friday at 9:30 AM IST. Show me the full schedule before you save it.

CHECKLIST

Setup checklist

  • Project created: "GTM Command Center" with the instructions pasted in.
  • Business Brief written and added to project knowledge.
  • Firecrawl connected and the competitor analysis done.
  • Brand Voice guide saved to project knowledge.
  • First SEO blog and 3 LinkedIn posts drafted.
  • Higgsfield connected and first UGC ad script approved.
  • Remotion project created with skills installed.
  • Typefully connected and first week of posts scheduled.
  • Monday kickoff prompt saved for next week.

Pro tips

  • Human in the loop: approve every post and video before it goes out.
  • Refresh monthly: update the Business Brief when offers or goals change.
  • Watch credits: video generation costs credits, so approve scripts first.
  • Protect keys: never share connector URLs or API keys in public.
  • Menus move: if a setting has moved, each tool's docs have the latest steps.
